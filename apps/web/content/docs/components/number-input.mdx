## Example

### Sizes

Pass the `size` prop to set the size of the NumberInput. Available sizes are `xs`, `sm`, `default`, `lg`, and `xl`.

<ComponentPreview name="c-number-input-2" />

### Controlled

Use `value` and `onValueChange` to control the input from state. The value is `null` when the input is empty.

<ComponentPreview name="c-number-input-3" />

### Minimum and maximum value

Pass the `min` prop or `max` prop to set an upper and lower limit for the input. By default, the input will restrict the value to stay within the specified range.

```tsx
function NumberInputDemo() {
  return <NumberInput min={0} max={10} />;
}
```
