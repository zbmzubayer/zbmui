The fastest way to get started is the ZBM UI CLI. It sets up your project and copies components into your codebase as source files you own — nothing is hidden behind an npm package.

## Quick start

### Initialize your project

```bash
npx @zbmui/cli@latest init
```

The CLI checks that your project meets the requirements (Next.js or Vite, Tailwind CSS v4, TypeScript path aliases), then writes a `components.json` config, installs the theme styles and the `cn()` utility, and adds any missing dependencies.

### Add components

```bash
npx @zbmui/cli@latest add button
```

Add multiple components at once — `npx @zbmui/cli@latest add button dialog tabs` — or run `add` with no arguments to pick from a list of everything the registry offers.

## Base UI setup

Whether you install via the CLI or manually, the following steps are required so Base UI components render correctly.

### Portals

Base UI uses portals for components that render popups, such as Dialog and Popover. To make portaled components always appear on top of the entire page, add the following style to your application layout root:

```tsx
<body>
  <div className="isolate">{children}</div>
</body>
```

### iOS 26+ Safari

Starting with iOS 26, Safari allows content beneath the UI chrome to be visible. Backdrops such as those used by dialogs must use `position: absolute` instead of `position: fixed` to cover the entire visual viewport. For this to work after the page is scrolled, the following style must be added to your global styles:

```tsx
<body className="relative">
  <div className="isolate">{children}</div>
</body>
```
