Welcome to the ZBM UI documentation! This guide will help you get started with using ZBM UI in your projects.

## What is ZBM UI?

ZBM UI is a modern and customizable UI component library built with React and TypeScript. It provides a wide range of pre-designed components that are easy to use and integrate into your applications.

## Key Features

- **Customizable**: Easily customize components to match your design requirements.
- **Accessible**: Built with accessibility in mind to ensure a great experience for all users.
- **Responsive**: Components are designed to be responsive and work well on all screen sizes.
- **TypeScript Support**: Fully typed components for better developer experience.
